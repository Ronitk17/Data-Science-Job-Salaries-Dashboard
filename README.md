# 💼 Data Science Job Salaries Dashboard

An interactive Tableau dashboard for analyzing data science job salaries and exploring salary trends across different roles, experience levels, locations, and employment characteristics.

## 📌 Overview

This project uses data visualization and analysis techniques to explore salary patterns in the data science job market.

The Tableau dashboard transforms job salary data into interactive visualizations, making it easier to compare salaries and identify trends across different job-related factors.

## 🎯 Objectives

- Analyze salary trends in the data science industry
- Compare salaries across different job roles
- Explore salary differences based on experience level
- Analyze salary patterns across different locations
- Understand employment and company-related salary trends
- Present insights through interactive Tableau visualizations

## 📊 Dashboard Analysis

The dashboard provides interactive visualizations for exploring:

- 💰 Salary distribution
- 👨‍💻 Job roles and salaries
- 📈 Experience level vs. salary
- 🌍 Location-based salary comparison
- 🏢 Company and employment characteristics
- 🔎 Interactive filtering and data exploration

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Data Analysis
- Data Cleaning
- Exploratory Data Analysis
